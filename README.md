# Smart MCQ Solver Challenge

## Competition Overview

This competition focuses on building AI/ML models that can solve challenging multiple-choice questions by predicting the **top 3 most likely answers** from options A–E. Instead of only identifying the correct answer, models must rank answers based on confidence and reasoning ability. The competition encourages experimentation with transformers, LLMs, retrieval-augmented systems, prompt engineering, and ensemble methods. Performance is evaluated using **MAP@3 (Mean Average Precision at 3)**, rewarding models that rank the correct answer higher in their predictions. This challenge provides hands-on experience in NLP, reasoning, answer ranking, and efficient AI system design.
